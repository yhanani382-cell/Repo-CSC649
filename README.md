CSC649: My First Python Experiment
Program Description
This Python program accepts a sentence from the user and calculates the number of words and characters in the sentence.
It also checks whether the user enters an empty input and displays an appropriate message.
How to Run
Open the project in PyCharm.
Make sure Python 3.12 is selected as the project interpreter.
Open main.py.
Run the program.
Enter a sentence when prompted.
Test Results
Test 1: Normal Sentence
Input: Python is easy to learn
Result: 5 words and 24 characters.
Pass
Test 2: Empty Input
Input: No input was entered.
Result: The program displays You did not enter a sentence.
Pass
Test 3: Extra Spaces
Input: Python is easy
Result: 3 words and 19 characters.
Pass
Limitation
The character count includes spaces and punctuation. Therefore, the character count represents all characters entered in the sentence rather than only letters.
